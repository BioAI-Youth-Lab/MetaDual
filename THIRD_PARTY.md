# Attribution and third-party materials

The original local GCN-SA README identifies its underlying work as **Self-Attention Empowered Graph Convolutional Network for Structure Learning and Node Embedding**. Historical class names and source mappings remain recorded in `docs/CODE_PROVENANCE.md` and the source manifests. No upstream copyright or license notice was deliberately removed from the supplied code.

The MetaDual manuscript explicitly states MIT licensing in its Code availability section. The project `LICENSE` reflects that declaration; the standard license text follows the [SPDX MIT reference](https://github.com/spdx/license-list-data/blob/main/text/MIT.txt). Public cohort data, biomedical model weights and remote LLM services remain subject to their providers' terms. The project license does not relicense those external materials or assert that the authors own the public datasets.

BiomedBERT is obtained separately via the configured local directory or model identifier. DeepSeek API credentials and model weights are not included. The supplied manuscript is treated as a local reference document and is not bundled for automatic public upload.
