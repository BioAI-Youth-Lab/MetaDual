# Data sources stated in the manuscript

The supplied manuscript attributes species-level relative abundance profiles and associated metadata to:

- Gupta, V. K., et al. **A predictive index for health status using species-level gut microbiome profiling.** Nature Communications 11(1):4635 (2020).
- Sun, W., et al. **A population-scale analysis of 36 gut microbiome studies reveals universal species signatures for common diseases.** npj Biofilms and Microbiomes 10(1):96 (2024).

The repository contains processed data from the authors' local experiment files. Source references/accessions below are transcribed from the supplied manuscript and do not imply a new independent audit of every public accession or its licensing.
